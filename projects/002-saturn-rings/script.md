# Saturn: The Rings Aren’t Solid

Audience: curious general viewers. Estimated duration: 35–45 seconds. Tone: wonder.
User delegated topic, script, and production choices; recommended direction selected.

Promise: reveal the swarm inside the familiar silhouette. Payoff: return to Saturn knowing what the rings contain. CTA: imagine the individual pieces next time you see Saturn.
